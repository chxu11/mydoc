# 🎯 学习三大目标

本站聚焦三条**互不重叠但相互补完**的学习主线。选一条先深入，另外两条按需查阅即可，不建议同时开三条。

---

## 阶段 1：🌐 前端

**为什么先学**：反馈最快，一小时就能写出一个能跑的页面；对建立编程直觉最友好。

**你会学到**：

- HTML / CSS：页面结构与视觉表达
- JavaScript：语言核心、异步、模块
- TypeScript：给 JS 加上类型，工程协作必备
- React：组件化、State、Hooks、路由、状态管理
- 工程化：Vite、ESLint、Git 工作流

**推荐入口**：
- 零基础 → 先看 [`docs/react/1.md`](../react/1.md)「React 是什么」建立整体感
- 有 JS 基础 → 直接跳到「阶段 3：组件与 Props」

---

## 阶段 2：🦀 Rust

**为什么学**：一门能让你**理解内存/并发/抽象**的语言。学完 Rust 后回看 C/Go/JS，很多模糊的概念突然清晰。

**你会学到**：

- 所有权、借用、生命周期（Rust 的灵魂）
- trait / 泛型 / 枚举模式匹配
- 错误处理：`Result` / `?` 运算符
- 并发：`Send` / `Sync` / `Arc<Mutex<T>>`
- 异步与 tokio
- 实战：命令行工具 → minishell → axum HTTP 服务

**推荐入口**：[Rust 介绍](../rust/1.md)

---

## 阶段 3：🐍 Python

**为什么学**：**广度冠军**。任何"我知道要做一件事但不知道选什么语言"的场景，Python 几乎都能兜底——爬虫、自动化、数据处理、AI。

**你会学到**：

- 语法与常用数据结构（含时间复杂度直觉）
- 面向对象、模块与包
- 装饰器 / 生成器 / 上下文管理器（Python 三件套）
- 标准库精选：`pathlib` `datetime` `json` `re`
- 常用三方：`requests` `pandas` `fastapi`
- 实战：爬虫 → 数据分析小报告 → FastAPI 小服务

**推荐入口**：[Python 介绍](../python/1.md)

## 🧭 三条主线的选择建议

```mermaid
flowchart TD
    A[我想学编程] --> B{想要什么反馈?}
    B -- 看得见摸得着的界面 --> FE[🌐 前端]
    B -- 深度理解计算机 --> RS[🦀 Rust]
    B -- 快速解决实际问题 --> PY[🐍 Python]

    FE --> FE2[做网站/小程序/后台]
    RS --> RS2[写工具/性能敏感服务/嵌入式]
    PY --> PY2[做脚本/数据/AI]
```

---

## 📅 推荐节奏

- **每周投入 3–5 小时**：约 3 个月走完一条主线入门阶段
- **一主线一实践**：每周留 1 小时写小 demo，比追教程进度更重要
- **交叉学习**：前端 + Python 组合适合做全栈小项目；Rust + Python 组合适合做性能敏感的科学计算工具
