# 阶段 1：物理地图

## 🎯 学习目标

- 看清物理的主要版块与先后关系
- 知道从牛顿到现代物理的主线是什么
- 建立"用数学描述世界"的视角

---

## 一、一句话比喻

> 物理像一套**描述世界的语法**：先学名词与基本句式（力学），再学复杂从句（电磁、相对论、量子）。

---

## 二、主要版块

| 版块 | 关键概念 | 依赖的数学 |
|---|---|---|
| **经典力学** | 力、动量、能量、振动 | 微积分、向量 |
| **电磁学** | 电场、磁场、麦克斯韦方程 | 向量微积分 |
| **热学** | 温度、熵、统计 | 概率 |
| **相对论** | 时空、光速不变 | 线代、张量 |
| **量子力学** | 叠加、概率幅 | 线代、复数 |

---

## 三、推荐路线

1. **先修**：经典力学（打基础，练微积分）
2. **再进**：电磁 + 振动与波
3. **进阶**：相对论 / 量子力学（需更强数学）

:::tip
经典力学的价值不只是"古老"，它是**训练用方程描述现实**的最佳起点。
:::

---

## 四、和本站其他栏目的关系

- 数学 → 物理的语言
- 纹样 → 对称性（物理里对称性决定守恒律）
- 编程 → 数值模拟、物理引擎

---

## ✅ 阶段总结

1. 物理是"用数学描述世界"的语法
2. 经典力学是最佳起点
3. 越往现代走，需要的数学越强

## 💡 练习题

> 本篇是路线图，所以题目是"读完全程再回来对答案"的自测。

1. **默写地图**：不查表，写出五个版块各自的核心概念与所需数学，并说明为什么量子力学排在最后。
2. **先后之争**：有同学想直接从量子入手（"那才是现代物理"）。用"数学门槛"和"建模训练"两条理由反驳他。
3. **跨栏连线**：本站说"纹样 → 对称性（物理里对称性决定守恒律）"。请举出一对具体的对称性与它对应的守恒量。

<details>
<summary>参考答案</summary>

1. 力学（力、动量、能量、振动 / 微积分与向量）→ 电磁（场、麦克斯韦方程 / 向量微积分）→ 热（温度、熵 / 概率）→ 相对论（时空、光速不变 / 线性代数与张量）→ 量子（叠加、概率幅 / 线性代数与复数）。量子排在最后，因为它要换掉"确定的轨迹"这套直觉，而新语言（希尔伯特空间、复振幅）本身就更抽象。
2. 一是数学门槛：量子的语言是线性代数与复数，跳级会变成背公式；二是建模训练：$F=ma$ 是"把现实写成方程再解回来"的最省力练习场，这个习惯没建立，读量子只能读比喻。
3. 例如：物理定律不随时间推移而改变（时间平移对称）对应**能量守恒**；空间平移对称对应**动量守恒**；旋转对称对应**角动量守恒**。这个对应关系叫诺特定理，也是"纹样栏的对称性"与物理真正相接的地方。

</details>
