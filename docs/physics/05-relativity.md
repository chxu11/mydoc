# 阶段 5：相对论 · 时空与 E=mc²

## 🎯 学习目标

- 接受"光速不变"这一反直觉的前提
- 理解时间膨胀、长度收缩、同时性是它的必然结果
- 说清 E = mc² 到底在说什么，以及引力为何变成"几何"

---

## 一、一句话比喻

> 想象每个人都在时空中以**恒定速率 c 前进**。你越把这份"前进"分给空间（运动得快），留给时间的就越少——于是**运动的钟走得慢**。

---

## 二、两条出发点（狭义相对论）

1. **物理定律在所有匀速参考系里形式相同**（没有特殊的"绝对静止"）
2. **真空光速 c 对所有观察者都一样**，无论光源或你怎么动

第二条是最反直觉的：你追光，光相对你**仍**是 c，不会变慢。为了守住它，**时间和空间只能自己让步**。

---

## 三、三条代价

| 结论 | 说法 | 何时明显 |
|---|---|---|
| **时间膨胀** | 运动的钟走得慢：Δt = γΔt₀ | 速度接近 c |
| **长度收缩** | 运动方向上被压短 | 速度接近 c |
| **同时性相对** | "两件事同时发生"取决于观察者 | 一般被忽略，却是根源 |

- γ = 1 / √(1 − v²/c²)，速度越接近光速，γ 越大，效应越夸张。
- 不是"看起来"慢，而是**真的**慢：μ 子因高速而"活得更久"，能到达地面被探测到。

:::tip
GPS 卫星既因高速（狭义）走得慢、又因高空引力弱（广义）走得快，两者都要**每天修正**，否则定位会漂移几公里。相对论不是哲学，是工程必修。
:::

---

## 四、E = mc²：质量就是被锁住的能量

- **m** 是质量，**c²** 是那个巨大的换算数（约 9×10¹⁶）。
- 含义：质量本身**蕴含**能量；一小块质量对应惊人的能量。
- 太阳为什么能烧几十亿年？核聚变把一点点质量"兑现"成光与热——**损失的重量 = 输出的能量**。
- 反之，能量也有"惯性"：给物体注入能量，它就略微变重。

---

## 五、广义相对论：引力 = 时空弯曲（概述）

狭义只管匀速。把**加速与引力**统一起来，需要更的一步：

- 等效原理：**引力**与**加速**在局部无法区分（电梯思想实验）。
- 于是爱因斯坦说：物质/能量告诉时空如何弯曲，弯曲的时空告诉物质如何运动。
- 地球绕太阳，不是因为被"拉"，而是沿着弯曲时空里的**最直路径（测地线）**走。
- 预言并证实：光线经过太阳会弯、引力红移、引力波、黑洞。

---

## ✅ 阶段总结

1. 一切从"光速不变"推出——时空为此让步
2. 时间膨胀 / 长度收缩 / 质能等价 E=mc² 是同一套逻辑的结果
3. 广义相对论把引力重新解释为时空的几何
