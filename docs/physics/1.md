# 阶段 1：物理地图

## 🎯 学习目标

- 看清物理的主要版块与先后关系
- 知道从牛顿到现代物理的主线是什么
- 建立"用数学描述世界"的视角

---

## 一、一句话比喻

> 物理像一套**描述世界的语法**：先学名词与基本句式（力学），再学复杂从句（电磁、相对论、量子）。

---

## 二、主要版块

| 版块 | 关键概念 | 依赖的数学 |
|---|---|---|
| **经典力学** | 力、动量、能量、振动 | 微积分、向量 |
| **电磁学** | 电场、磁场、麦克斯韦方程 | 向量微积分 |
| **热学** | 温度、熵、统计 | 概率 |
| **相对论** | 时空、光速不变 | 线代、张量 |
| **量子力学** | 叠加、概率幅 | 线代、复数 |

---

## 三、推荐路线

1. **先修**：经典力学（打基础，练微积分）
2. **再进**：电磁 + 振动与波
3. **进阶**：相对论 / 量子力学（需更强数学）

:::tip
经典力学的价值不只是"古老"，它是**训练用方程描述现实**的最佳起点。
:::

---

## 四、和本站其他栏目的关系

- 数学 → 物理的语言
- 纹样 → 对称性（物理里对称性决定守恒律）
- 编程 → 数值模拟、物理引擎

---

## ✅ 阶段总结

1. 物理是"用数学描述世界"的语法
2. 经典力学是最佳起点
3. 越往现代走，需要的数学越强
