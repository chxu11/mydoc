# 阶段 1：Rust 是什么

## 🎯 学习目标

- 理解 Rust 的定位：为什么有人在 C/C++/Go/Java 之外还要学 Rust
- 知道 Rust 能做什么、不适合做什么
- 建立正确的心智模型，为后面「所有权 / 借用 / 生命周期」三座大山做心理建设

---

## 🍔 一句话比喻

> **Rust 像一个"严格的空管"**：在飞机（程序）起飞（编译）之前，会反复确认燃油、载重、航线是否合规；一旦放行，飞行途中几乎不会出事故（运行时内存安全）。
>
> 学 Rust 的**痛苦在起飞前**（和编译器搏斗），**回报在降落后**（生产环境几乎零内存 bug）。

---

## 📚 Rust 适合做什么

| 场景 | 代表项目 / 生态 |
|---|---|
| 命令行工具 | ripgrep、fd、delta、uv |
| Web 后端 | axum、actix-web、tokio |
| 系统 / 嵌入式 | 操作系统内核组件、固件 |
| 前端工程链 | SWC、Rspack、Turbopack（用 Rust 重写 JS 工具） |
| wasm | 浏览器内高性能模块 |

## ⚠️ Rust 不太适合

- 快速原型 / 脚本胶水（Python / Node 更爽）
- 强依赖复杂 GC 生态的场景（如某些企业级 Java 框架）

## ✅ 阶段 1 总结

1. Rust 是**系统级 + 内存安全 + 零成本抽象**的语言，学习曲线陡但回报大
2. 前期最大的门槛是**所有权系统**，本站会用"借书证 / 共享钥匙"这类比喻帮你直觉理解
3. 建议边看边做 [Rustlings](https://github.com/rust-lang/rustlings) 练习
