# 1. Docusaurus 介绍

## 🎯 学习目标

- 理解 Docusaurus 是什么、适合解决什么问题
- 知道它相对于 VuePress / MkDocs / GitBook 的定位差异
- 建立"配置文件 → Markdown → 静态产物"的心智模型

---

## 🍔 一句话比喻

> **Docusaurus 像"面向开发者的公众号后台"**：你只管写 Markdown，它负责帮你
> 生成带侧边栏 / 搜索 / 深色模式 / 版本号 / SEO meta 的静态站，一条命令部署到 GitHub Pages。

---

## 一、Docusaurus 是什么

由 Meta 开源的**静态网站生成器**，专为文档站设计：

- **Markdown + MDX**：普通文档用 md，需要在文档里嵌 React 组件时用 MDX
- **React 驱动**：整站是 SPA，页面切换几乎瞬时
- **两大内容插件**：`docs`（文档）与 `blog`（博客），本站只用了 docs
- **主题可插拔**：`@docusaurus/theme-classic` 覆盖 90% 需求，剩下 10% 用 swizzle 定制

---

## 二、什么时候选它，什么时候不选

### ✅ 适合

- **技术文档站 / 教程站 / 知识库**（本站就属于这一类）
- 需要**多版本文档**（v1 / v2 并存）
- 需要 **i18n**（同一份文档多语言）
- 团队习惯 **Markdown + Git 工作流**

### ❌ 不适合

- **营销官网**（页面高度定制、几乎无文字） → 用 Next.js / Astro
- **纯个人博客** → Hugo / Astro 更快
- **超大文档站（> 5000 篇）** → 构建会慢，考虑 mkdocs + material 主题

## 三、核心文件一览

```
项目根/
├── docusaurus.config.js   # 站点级配置（标题 / 导航 / 主题 / 插件）
├── sidebars.js            # 侧边栏结构（可自动生成）
├── docs/                  # 文档 Markdown 目录
│   ├── intro.md
│   └── react/1.md ...
├── src/
│   ├── css/custom.css     # 主题变量覆盖
│   └── pages/index.js     # 首页组件
├── static/                # 静态资源（图片 / favicon），会被原样拷到 build/
└── build/                 # 构建产物（部署时上传这个目录）
```

:::tip 关键约定
`docs/` 下的目录结构 **直接决定 URL 路径**：
`docs/rust/4.md` → 站点上线后地址就是 `/mydoc/docs/rust/4`。
这也是为什么"目录重命名 = URL 迁移"要谨慎评估。
:::

## 四、常用命令

```bash
# 开发：热更新，http://localhost:3000
npm start

# 构建：生成 build/
npm run build

# 本地预览构建产物（更接近生产）
npm run serve

# 清理缓存
npm run clear
```

## 五、部署

Docusaurus 是**纯静态**产物，任何静态托管都行：

| 平台 | 说明 |
|---|---|
| GitHub Pages | 官方内置 `docusaurus deploy`；本站用 GitHub Actions 自动化 |
| Vercel / Netlify | 关联 Git 仓库即可，PR 自动预览 |
| Cloudflare Pages | 构建命令 `npm run build`，输出目录 `build` |
| 自建 Nginx | 把 `build/` 拷到服务器，纯静态服务 |

:::warning GitHub Pages 需要 baseUrl
部署到 `https://<用户>.github.io/<仓库>/` 时，`docusaurus.config.js` 必须：
```js
url: 'https://<用户>.github.io',
baseUrl: '/<仓库>/',
```
少一个都会导致资源 404。
:::

## 六、进阶方向

本站已用到：

- `@easyops-cn/docusaurus-search-local` — 中英文站内搜索
- `@docusaurus/theme-mermaid` — 文档里画流程图 / 状态机
- `@docusaurus/theme-live-codeblock` — 代码块可编辑并即时运行
- `frontmatter tags` — 自动生成标签索引页（本站标签与栏目一一对应，导航栏未单独挂出）

你可能还想知道：

- **swizzle**：覆盖官方主题组件（如自定义 DocItem 底部）
- **多版本文档**：`npm run docs:version 1.0`
- **i18n**：新增 `i18n/zh/` `i18n/en/` 平行内容
- **plugin-google-gtag**：接入访问统计

## ✅ 阶段总结
