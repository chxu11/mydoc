# 👋 欢迎来到胖头鱼学习网站

这是一个基于 Docusaurus 搭建的**编程教程学习平台**，聚焦三条主线（每条保持“介绍 · 环境 · 基础 · 核心概念” 3–4 篇的概览节奏）：

- 🌐 **前端**：已上线 8 篇 React 入门（含 TodoList 实战）；后续覆盖 JavaScript 基础、TypeScript、HTML/CSS 与工程化
- 🦀 **Rust**：已上线 4 篇基础（介绍 / 环境 / 变量与类型 / ⭐ 所有权）；后续覆盖借用与生命周期、trait、错误处理与并发
- 🐍 **Python**：已上线 4 篇基础（介绍 / 环境 / 变量与控制流 / 数据结构与推导式）；后续覆盖面向对象、装饰器与常用库

## 🚀 如何开始

1. 顶部导航选择 **🎯 学习方向**，进入任一主线的第一篇「介绍」
2. 每篇教程都遵循统一模板：**学习目标 → 通俗比喻 → 原理 → 对比示例 → 常见坑 → 练习 → 总结**
3. 建议按侧边栏顺序阅读，`阶段 X` 编号即推荐学习次序

## 📖 写作规范（贡献前必读）

每个 Markdown 文件顶部必须包含 frontmatter：

```yaml
---
id: 3
title: 3.组件与Props
sidebar_position: 3
description: 一句话描述本章学什么（用于 SEO 与列表页）
keywords: [React, Props]
tags: [前端, React]
---
```

**其它约定**：

- 单文件建议不超过 **400 行**，超过请按子主题拆分
- 代码块必须写语言标签（`js` / `rust` / `python` / `bash`），前端示例可加 `live` 变成可编辑运行
- 概念性内容推荐插入 `mermaid` 图表
- 提示框使用 `:::tip` / `:::warning` / `:::danger` / `:::info` / `:::note`

## 🔍 找不到内容？

- 顶部导航右侧有**站内搜索**（中英文都支持）
- 每篇底部有**编辑此页**按钮，发现错漏欢迎直接提 PR

Happy hacking! 🎣
