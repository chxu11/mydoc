# 阶段 7：育儿语录 · 把伤人的话说好听

## 🎯 学习目标

- 认出三种"脱口而出但伤人"的句式
- 记住十组可以直接换用的说法
- 掌握背后的三步转换公式，能自己造句

---

## 一、一句话比喻

> 同一句「都是因为你」，是苦药还是甜汤，取决于**方向**：后面接"我这么累"，是怪罪；接"我们每天都开心"，是感谢。字没变，孩子听到的是两个世界。

---

## 二、十组"换个说法"

| 顺口想说的 | 不妨改成 |
|---|---|
| 都是因为你，我才这么累。 | 都是因为你，我们的每一天都感到特别开心。 |
| 你怎么这么笨，讲了几遍还不会！ | 这一部分有点难，我们放慢速度，再来一遍。 |
| 你看人家 ×××，再看看你！ | 你比上个月进步了不少，我都看到了。 |
| 再哭！再哭就不要你了！ | 想哭就哭一会儿，我就在这儿陪着你。 |
| 我为你付出这么多，你却不争气。 | 你认真做事的样子，就是对我最好的回报。 |
| 别烦我，没看我正忙着吗？ | 给我十分钟，忙完我专门听你说。 |
| 就知道玩，作业一个字不写！ | 先痛快玩一会儿，再专心写，我们一起定个时间。 |
| 我像你这么大的时候早会了。 | 每个人有自己的时区，你也在往前走。 |
| 你再这样，我可要生气了！ | 你这样做，我有点担心，也有点累。 |
| 真是受够你了。 | 我现在情绪不太好，我们先各自冷静五分钟。 |

:::tip
注意最后几组的共同套路：**不压情绪，只换表达。** 累和担心是真的，可以照说——说的主语从"你真糟糕"换成"我有点累"，火气有了出口，孩子不被烧到。
:::

---

## 三、三步转换公式

1. **怪罪归因 → 感谢归因**
   "都是因为你 + 我受的苦" 改成 "都是因为你 + 我得着的甜"。同一因果链，方向调头。
2. **"你跟我"对立 → "我们"**
   "你去写作业" → "我们把作业这一关过了"。从指挥官，变成同队队友。
3. **贴标签 / 威胁 → 描述行为 + 说出感受**
   "你怎么这么磨蹭"（判决）→ "还有五分钟要出门，我有点着急"（事实 + 感受）。孩子知道发生了什么，而不是"我是个什么样的人"。

> 比较的坐标也换掉：拿孩子和**上个月的他自己**比，而不是和"别人家孩子"比。

---

## 四、说错了怎么办：修复比完美重要

- 没忍住说完重话，事后补一句就行："刚才妈妈/爸爸那样说，不好。我其实想说的是……"
- 不需要大人式的道歉仪式，**如实重说一遍**就够了——孩子的原谅能力远超大人想象。
- 记一本"语录小账"（呼应[做笔记的方法](../education/4.md)）：本周哪句最常脱口而出，下周就只练那一句的替换版。

:::warning
好话的前提是安全，不是忍着。涉及底线（安全、不伤害人、不尊重人）时，要清楚地说"不行"——**温和而坚定的"不行"，也是好话的一半。** 本栏目换的是伤人的废话，不是该立的规矩。
:::

---

## ✅ 阶段总结

1. 同一句式可以两个方向说：把「都是因为你」从怪罪调头成感谢
2. 三步公式：怪罪→感谢、你对着我→我们一起、贴标签→说感受
3. 偶尔说错正常，事后的"修复"本身就是最好的示范
