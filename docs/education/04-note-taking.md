# 阶段 4：做笔记的方法

## 🎯 学习目标

- 明白笔记的目的不是"记录"，而是"日后可用、能再生产想法"
- 掌握两种即学即用的格式：康奈尔、原子卡片
- 理解"链接"如何让笔记之间产生复利

---

## 一、一句话比喻

> 烂笔记像**仓库**，只进不出，越堆越乱；好笔记像**花园**，每条目是一颗能嫁接的种子，彼此连着，自己会长出新东西。

---

## 二、先分清三种笔记

| 类型 | 为谁写 | 特点 |
|---|---|---|
| **闪念笔记** | 稍后的自己 | 随手抓，需尽快整理，否则变垃圾 |
| **文献笔记** | 忠于原文 | 摘要点，标出处，尽量短 |
| **永久笔记** | 服务于你的问题 | **用自己的话**、一条一个想法、可被链接 |

:::tip
决定价值的是**永久笔记**：它是"因为你才存在"的内容，而不是作者原话的复印件。
:::

---

## 三、两种可直接上手的形式

**① 康奈尔笔记**（适合听讲课 / 读书）

```text
┌──────────────┬────────┐
│  线索栏       │        │
│ (关键词/问题) │ 内容区  │
│              │(课堂要点)│
├──────────────┴────────┤
│  总结：一句话复述本页    │
└───────────────────────┘
```
左栏写"问题/线索"，日后盖住右栏自测——天然对接[主动回忆](../education/02-spaced-repetition.md)。

**② 原子卡片（Zettelkasten）**（适合长期积累）

- 一张卡 = **一个**想法，标题即结论
- 写**完整的一句自己的话**，能脱离上下文看懂
- 卡末写"它支持 / 反驳 / 关联"哪几张卡

---

## 四、复利来自"链接"

- 单条笔记是死的；把相关条目**连起来**，才形成结构。
- 新写一张卡时问自己：**它和我已有的哪张卡有关？是补强还是反对？**
- 久了会出现"枢纽卡"——很多线索在此交汇，往往就是你**下一个文章/项目**的雏形。

> 卢曼（Niklas Luhmann）靠这套卡片盒一生写了数十部著作，他说：**"我不做任何事，都是和卡片箱对话。"**

---

## ✅ 阶段总结

1. 为"日后可用"而写，重点在用自己的话的永久笔记
2. 康奈尔管"输入时"，原子卡片管"长期沉淀"
3. 链接产生复利，枢纽卡长出输出
