# 阶段 1：怎么学一门硬知识

## 🎯 学习目标

- 把"我要学 X"拆成可执行的流程
- 掌握费曼式学习与刻意练习
- 学会用"输出"检验是否真的懂

---

## 一、一句话比喻

> 学硬知识像**栽树**：先有根（地图与动机），再有干（核心概念），最后枝叶（细节）。很多人一上来就摘叶子，越学越乱。

---

## 二、四步流程

1. **搭地图**：先看目录/导论，知道全貌与前后依赖
2. **最小闭环**：选一个最小可用的主题，立刻动手
3. **费曼输出**：用大白话讲给别人（或写下来），卡壳处 = 没懂
4. **间隔复习**：隔 1 天 / 3 天 / 7 天重访，对抗遗忘

---

## 三、费曼技巧

- 假装讲给一个**完全不懂的人**
- 用类比、比喻，而不是术语
- 讲不下去的地方，**回去重读**
- 简化、删掉行话，直到"一句话能说清"

:::tip
**能写清楚，才算真懂。** 这也是本站每篇教程都带「阶段总结」的原因。
:::

---

## 四、刻意练习

不是"重复做"，而是：

- **有明确目标**（这次练什么）
- **在舒适区边缘**（有点难但够得着）
- **立刻获得反馈**（编译报错、测试、对答案）
- **反复攻克弱点**（而非重复已会的）

---

## ✅ 阶段总结

1. 先地图，再最小闭环
2. 费曼输出检验理解
3. 刻意练习 = 目标 + 边缘 + 反馈 + 补弱
