# 1. 证明方法巡礼

## 🎯 为什么"证明"值得单独开一栏
数学与其他学科最大的分水岭，是它**不接受"大概是"**。
- 物理学靠观测：观察到 10000 次apple落地，也不敢说"永远"
- 法学靠判例：上一个判决不能锁死下一个
- **数学靠证明**：一条逻辑链一旦闭合，就是**永远**。

两千多年前，欧几里得写《几何原本》，把当时散落的几何知识**全部还原到 5 条公设**上。这是人类第一次尝试把知识建立在"不可辩驳的推理"之上——**这个传统至今是数学的心脏**。
学证明，不是变成数学家，而是掌握一种**"我说的每句话都能追溯到一个起点"的思维纪律**。这一栏挑出**最经典 5 个证明**，让你 20 分钟体验什么叫"美的逻辑"。

## 一、四种基本证明方法

### 1. 直接证明（Direct Proof）
**套路**：从已知条件出发，一步接一步推到目标。
**例**：证明"两个偶数之和是偶数"。
- 设 a = 2m, b = 2n
- 则 a + b = 2m + 2n = 2(m + n)
- 由定义，2(m+n) 是偶数 ∎

**特点**：最"老实"，也最朴素。数学里 60% 命题都能这么处理。

### 2. 反证法（Proof by Contradiction）
**套路**：**假设结论为假**，推出逻辑矛盾，于是原结论必须为真。
**经典**：√2 是无理数。
- 假设 √2 = p/q 为有理数（p, q 互质）
- 推出 p² = 2q² → p 是偶数 → 设 p = 2k → q 也是偶数
- 与"p, q 互质"矛盾 → 假设错误 ∎

**特点**：**"如果它不成立，宇宙就崩了"**——最有力也最优雅。见[第 3 篇](/mydoc/docs/math/3)。

### 3. 数学归纳法（Mathematical Induction）
**套路**：**两步**——
- **基础步**：n = 1 时命题成立
- **归纳步**：假设 n = k 成立 → 证明 n = k+1 也成立

两步都过 → 对所有自然数 n 都成立。
**比喻**：**多米诺骨牌**——只要第一张倒、任何一张倒都会推倒下一张，那么所有牌都会倒。
**经典**：1 + 2 + ... + n = n(n+1)/2。见[第 5 篇](/mydoc/docs/math/5)。

### 4. 构造法（Proof by Construction）
**套路**：不绕弯子，**直接给出一个满足条件的例子**，证明"存在"。
**例**：证明"存在两个无理数 a, b 使 a^b 为有理数"。
- 考虑 √2^√2。若它是有理数 → a = b = √2 就完事
- 若它是无理数 → 令 a = √2^√2, b = √2，则 a^b = (√2^√2)^√2 = √2^2 = 2 是有理数
- 两种情形都存在满足条件的对 ∎

**特点**：有时甚至**不需要知道 √2^√2 到底是不是有理数**——构造法的浪漫。

## 四、"证明"到底在证明什么
数学证明不是"说服别人"，而是**把命题还原成几个不可再分的公理**。
一个证明完成后，你得到的不只是一个结论，而是：
- 一条**"从 A 到 B 的必然通道"**
- 一组**可以复用的引理**（lemma）
- 一种**"下一次遇到类似命题该怎么想"的直觉**

这就是为什么学证明**比记公式值一万倍**——公式会过时，思维方式不会。
