# 阶段 3：变量与控制流

## 🎯 学习目标

- 建立"**变量是标签，不是盒子**"的正确 Python 心智模型
- 会用**类型注解**写出可维护的现代 Python（PEP 484 / PEP 604）
- 掌握 f-string 全部常用能力
- 理解 `for/else`、`match`（Python 3.10+）等**独有语法**
- 避开**可变默认参数**这一经典大坑

---

## 🍔 一句话比喻

> **Python 的变量像"给物体贴便利贴"**：
> - `x = [1, 2]`：创建一个 list 对象，把便利贴"x"贴上去
> - `y = x`：**同一张便利贴**再多写一个 y（不是复制！）
> - `x = [3, 4]`：把 x 便利贴**撕下来**，贴到另一个新 list 上——原来的 `[1, 2]` 还活着，只是现在只有 y 指着
>
> 这解释了为什么 `y.append(99)` 会同时改变 `x`——它们本来就是**同一张贴纸**。

## 一、变量与赋值

Python **不需要声明**，赋值即创建：

```python
name = "胖头鱼"      # str
age = 25             # int
pi = 3.14            # float
ok = True            # bool
nothing = None       # NoneType（不是 NULL 不是 0！）
```

### 多重赋值

```python
a, b = 1, 2              # 元组解包
a, b = b, a              # 一行交换
x = y = z = 0            # 三个变量指向同一个 int 对象
first, *rest = [1, 2, 3, 4]  # first=1, rest=[2,3,4]
```

### 命名规范（PEP 8）

- 变量、函数：`snake_case`
- 类：`PascalCase`
- 常量：`UPPER_SNAKE_CASE`
- 私有：前缀下划线 `_internal`

## 二、动态类型 vs 类型注解

Python 是**动态强类型**——运行时才知道类型，且不做隐式转换：

```python
1 + "1"  # ❌ TypeError，不会自动转 str
```

**类型注解**（3.5+）：只是提示，运行时不强制：

```python
def greet(name: str, times: int = 1) -> str:
    return f"Hi {name}! " * times

greet(123)   # ⚠️ 类型检查器（mypy/pyright）会警告，但运行不报错
```

### 现代注解写法（3.10+）

```python
from typing import Optional, Union

x: int | None = None              # PEP 604，等价 Optional[int]
y: int | str = 42                 # 等价 Union[int, str]
lst: list[int] = [1, 2, 3]
d: dict[str, int] = {"a": 1}
```

:::tip 用 pyright / mypy 才是"真"类型检查
注解本身零成本，但配上 `pyright` 或 `mypy`，你在 VS Code 里就能提前抓到 90% 的类型 bug——这是现代 Python 项目的标配。
:::

## 三、数字与字符串

### 数字

```python
x = 10
y = 3
print(x / y)     # 3.333… 真除法
print(x // y)    # 3      向下取整
print(x % y)     # 1      取余
print(x ** y)    # 1000   幂
big = 10 ** 100  # Python int 是任意精度，不会像 C 溢出
```

### 字符串

```python
s = "胖头鱼 学习"
print(len(s))          # 6
print(s.upper())
print(s.replace("学习", "教学"))
print(s.split())       # ['胖头鱼', '学习']

# 三引号：多行
sql = """
SELECT *
FROM users
WHERE active = 1
"""
```

### f-string（**必会**）

```python
name, age = "胖头鱼", 25
print(f"{name} 今年 {age} 岁")
print(f"明年 {age + 1} 岁")                 # 支持表达式
print(f"{'居中':^20}|")                      # 对齐：左< 右> 中^
print(f"{3.14159:.2f}")                      # 保留 2 位 → 3.14
print(f"{10**6:_}")                          # 千位分隔 → 1_000_000
print(f"{name=}")                            # 调试神器 → name='胖头鱼'
```

## 四、布尔与真值

Python 里被视为 `False`（假值）的：

```
False  None  0  0.0  ""  []  {}  ()  set()
```

**其他一切都是 True**——包括 `-1`、`"0"`、`[0]`。

**短路求值**：

```python
name = input("名字：") or "匿名"    # 空串走右边
result = find_maybe() or fallback()
```

**三元表达式**：

```python
status = "成年" if age >= 18 else "未成年"
```

## 五、控制流

### if / elif / else

```python
if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"
```

### for + range

```python
for i in range(5):        # 0 1 2 3 4
    print(i)

for i in range(1, 10, 2): # 1 3 5 7 9
    ...

for idx, val in enumerate(["a", "b", "c"]):
    print(idx, val)

for k, v in {"x": 1, "y": 2}.items():
    print(k, v)
```

### while

```python
n = 0
while n < 5:
    n += 1        # ⚠️ Python 没有 ++
```

### break / continue / **else**

Python 独有：`for/else`、`while/else` 里的 `else`——**"没有 break 过"才执行**，非常适合"找遍了没找到"的场景：

```python
for num in [2, 4, 6, 8]:
    if num % 3 == 0:
        print("找到 3 的倍数")
        break
else:
    print("没有找到")     # 只有循环自然结束（没 break）才执行
```

### match（3.10+）：结构化"模式匹配"

比 switch 强大得多——**能解构、能捕获、能 guard**：

```python
def http_status(status):
    match status:
        case 200:
            return "OK"
        case 404:
            return "Not Found"
        case 301 | 302 | 307 | 308:
            return "Redirect"
        case 500 if is_debug:           # guard
            return "Internal (debug)"
        case [200, msg]:                # 列表解构
            return f"OK: {msg}"
        case {"user": u, "role": r}:    # 字典解构
            return f"{u} is {r}"
        case _:
            return "Unknown"
```

## 六、逻辑运算符与"没有 ++"

```python
# ✅ 与或非
if age >= 18 and country == "CN":
    ...

# ❌ 不要写 & | （位运算，只对 bool 侥幸能跑）

# ⚠️ Python 没有 i++ / i--
i += 1
```

**`is` vs `==`**：

| | 含义 | 用于 |
|---|---|---|
| `==` | 值相等 | **99% 场景** |
| `is` | 同一对象（内存身份） | **只用于 `x is None` / `x is True`** |

:::warning 反例
```python
a = 256; b = 256
print(a is b)   # True（小整数缓存）
a = 257; b = 257
print(a is b)   # False！不同对象
```
**永远用 `==` 比较数值，用 `is` 判断 `None`。**
:::

## 七、⚠️ 可变默认参数：经典大坑

```python
def add(item, lst=[]):    # ❌ 默认参数只在函数定义时求值一次！
    lst.append(item)
    return lst

print(add(1))   # [1]
print(add(2))   # [1, 2]     ← 惊了！上次的 [1] 被复用
print(add(3))   # [1, 2, 3]
```

**正确写法**：默认 `None` + 函数体里判断：

```python
def add(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

:::tip 一句话口诀
**默认参数只能是 `None` / 数字 / 字符串 / 元组等不可变类型**；要 `[` `{` `set()` 一律 `None` + 内部初始化。
:::

## 八、作用域：LEGB 规则

Python 变量查找顺序：**L**ocal → **E**nclosing → **G**lobal → **B**uiltin。

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)       # local
    inner()
```

想在外层函数里改 `x`？显式声明：

```python
def outer():
    x = 1
    def inner():
        nonlocal x     # 改的是外层
        x += 1
    inner()
    print(x)           # 2
```

:::warning `global` 尽量少用
除非配置常量 / 单例，用 `global` 通常意味着设计问题。
:::

## ✅ 阶段 3 总结

1. **变量 = 便利贴，不是盒子**——理解这一点，`is`/`==`、可变默认参数等一系列坑都通了
2. **动态强类型 + 类型注解 + pyright**，是现代 Python 的黄金组合
3. **f-string 支持表达式、格式化、调试**，能不用别的字符串拼接就不用
4. **`for/else`、`match`、`nonlocal`**——这三个语法是 Python 特色，值得掌握
5. **默认参数**只能用不可变类型；可变容器一律 `None` + 内构造
