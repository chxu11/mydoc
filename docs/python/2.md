# 阶段 2：环境搭建

## 🎯 学习目标

- 选对**版本管理器**（pyenv）与**包管理器**（uv / pip / poetry）
- 用虚拟环境隔离不同项目，避免"全局 Python 越装越乱"
- 在 VS Code 中一键切换解释器，跑通第一段脚本

---

## 🍔 一句话理解工具分工

> - **python 本身** = 引擎
> - **pyenv** = 多引擎切换器（同时有 3.9 / 3.11 / 3.12 各版本）
> - **venv / uv / poetry** = 给每个项目单独准备一个"工具箱"（虚拟环境），互不干扰
> - **pip** = 从 PyPI 往工具箱里放包的搬运工

:::info 一句话推荐
2026 年起步：**pyenv 管版本 + uv 管依赖**，比 `pip install` 快 10–100 倍，且兼容现有 pip / venv 生态。
:::

## 一、安装 Python

### macOS

```bash
# 推荐用 pyenv，能装多版本共存
brew install pyenv

# 装 3.12（或你想要的版本）
pyenv install 3.12.7
pyenv global 3.12.7

# 让 shell 找到 pyenv（zsh 用户）
echo 'eval "$(pyenv init -)"' >> ~/.zshrc
exec zsh

python --version  # Python 3.12.7
```

### Windows

从 [python.org](https://www.python.org/downloads/) 下载 3.12+ 安装包，勾选 **Add Python to PATH**。多版本管理推荐 [pyenv-win](https://github.com/pyenv-win/pyenv-win)。

### Linux

发行版自带的 `python3` 通常够用，但版本往往偏老。同样推荐 pyenv。

## 二、包管理器：选 uv（推荐）或 poetry

### 安装 uv

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows PowerShell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 创建项目（uv 工作流）

```bash
uv init hello_py
cd hello_py
uv add requests          # 添加依赖，写入 pyproject.toml
uv run python main.py    # 在项目虚拟环境里运行
```

生成的结构：

```
hello_py/
├── pyproject.toml       # 项目元信息 + 依赖声明
├── main.py
└── .venv/               # 自动创建的虚拟环境
```

:::tip 只用现有 pip 也可以
`python -m venv .venv && source .venv/bin/activate && pip install requests`
但**永远不要用系统 Python 直接 `pip install`**——一旦污染很难回滚。
:::

## 三、VS Code 配置

1. 装扩展：**Python**（Microsoft 官方） + **Pylance**（语言服务器）
2. 打开项目后，`Cmd/Ctrl + Shift + P` → **Python: Select Interpreter** → 选 `.venv`
3. `settings.json` 推荐：

```json
{
  "python.formatting.provider": "black",
  "[python]": {
    "editor.defaultFormatter": "ms-python.python",
    "editor.formatOnSave": true
  },
  "python.analysis.typeCheckingMode": "basic"
}
```

保存文件自动 `black` 格式化 + `Pylance` 类型检查。

## 四、跑通第一段脚本

```python
# main.py
def greet(name: str) -> str:
    return f"Hello, {name}! 🐍"

if __name__ == "__main__":
    print(greet("胖头鱼"))
```

运行：

```bash
uv run python main.py
# Hello, 胖头鱼! 🐍
```

## 五、常见坑

:::warning `pip` 和 `pip3` 混着用
Python 2 已 EOL，任何环境都统一 `pip3` 或 `python -m pip`，避免装到已删掉的旧 Python。
:::

:::warning 全局 `pip install`
只要出现 `pip install xxx` 不带 venv 前缀，就是在污染系统 Python。macOS 尤其危险，某些系统工具会依赖特定版本。
:::

:::warning 忘记 `requirements.txt`
用 uv / poetry 的项目，**依赖信息在 `pyproject.toml` + `uv.lock` / `poetry.lock`**，别再手动维护 requirements.txt。
:::

## ✅ 阶段 2 总结

1. **pyenv 管版本，uv 管依赖，venv 隔离项目**——三者各司其职，别混
2. VS Code + Pylance 已经能覆盖 90% 的开发体验需求
3. 一旦养成"新项目 = 新虚拟环境"的习惯，之后不会再遇到"装 A 项目把 B 项目跑崩"的问题

## 💡 动手练习

1. 用 uv 初始化一个新项目，加 `rich`，用 `rich.print("[bold green]胖头鱼[/]")` 打印彩色文字
2. 故意在系统 Python 里 `pip install requests` 然后卸载，理解为什么"全局装包"很难干净回滚
3. 把当前项目的 `.venv` 删掉，用 `uv sync` 一键复原——体验 lockfile 的价值
