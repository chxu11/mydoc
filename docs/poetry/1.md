# 阶段 1：诗歌文章 · 导读

## 🎯 本栏为什么存在

前面几栏（编程、纹样、数学、物理）训练**理性的精确**；
这一栏训练**感性的精确**——用最少的字，把最复杂的处境说清楚。

> 一个既能读证明、又能读诗的人，才不容易活成一块只会计算的芯片。

## 怎么读这一栏

1. **先读原文**，别急着看赏析——让第一印象留一会儿。
2. **出声念**：古诗词、骈散句，念出来才知道好在哪。
3. **再读赏析**，重点看"它为什么这样写"。
4. **试着复述**：合上书，用自己的话讲出主旨（费曼技巧同样适用）。

## ✅ 阶段总结

3. 文与理互为镜像：一个给答案，一个给处境
