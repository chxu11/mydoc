# 2. 云雷纹 · 天地的呼吸

*新石器晚期发端 → 商周鼎盛 → 汉后衰微 → 现代重生。回环的线条，四千年来从未彻底断过。*

---

### 源头 · 良渚玉琮兽面纹（约前 3300–前 2300）

<img src={useBaseUrl("/img/docs/jade_cong_with_sacred_human-animal_motif-w900-5038f699.jpg")} alt="良渚玉琮上的神人兽面纹" loading="lazy" decoding="async" />

*目前所知最早的"回环地纹"。玉琮神人兽面像周围密布细如发丝的卷云线，用燧石尖刻成。*

---

### 鼎盛 · 商周青铜器的地纹（约前 1600–前 256）

<img src={useBaseUrl("/img/docs/file-w900-4b96f6d6.jpg")} alt="云雷纹青铜角（西周）" loading="lazy" decoding="async" />

*柳州博物馆藏西周青铜角。兽面纹为主纹、云雷纹为地纹——主与地的对比是商周铜器装饰的核心语法。*

---

### 南方余响 · 壮族云雷纹铜鼓（唐–宋）

<img src={useBaseUrl("/img/docs/file-w900-b8ce7d94.jpg")} alt="云雷纹大铜鼓" loading="lazy" decoding="async" />

*中原青铜礼器式微之后，云雷纹在岭南铜鼓上活了下来。鼓面一圈圈同心回纹，是祭雷雨的礼器记忆。*

---

### 现代 · 从县徽到 Versace 都是它

云雷纹的方折回环版本叫"**回纹**"，今日仍然常见：

- 中国许多城市徽标（如合肥、安阳）的核心图形元素
- 高铁站台地面铺装
- 建筑栏杆、窗棂、瓷器口沿

它和隔壁 [Greek Key](./03-greek-key.md) 结构上高度同构——都是"一条线自我折叠成矩形螺旋"。学界长期争论东西方是否同源，目前主流观点是**独立发明、结构必然**。

---

## 动手 · 把「雷」磨成「云」

<PatternLab kind="leiwen">

同一个方折螺旋，圆角拉到 0 就是商周铜器上的**雷纹**——方折、冷硬，像闪电劈下来；
一路推到 1，拐角变圆，立刻成了**云纹**——卷曲、绵软，像气流打旋。
古人把云和雷画进同一套语法，靠的正是这一个参数；两千五百年后，它变成滑杆上的 21 档。
再把「每行几个螺旋」拉到 3：单一个螺旋只是图案，一排排镜像咬起来才是满地雷纹——
相邻两个旋向相反，一个顺时针、一个逆时针，彼此的缺口正好互补，这正是铜鼓地子上那种铺法。
把「相邻格旋向」切成全部同旋，图样并不难看，只是每个螺旋的开口都朝同一边，
邻格之间空出的缝隙不再互相嵌住——匠人说的“咬得住”与“咬不住”，差的就是这一个开关。

</PatternLab>

几何上它只是一条**方螺旋**：每转两段，边长加一个步长。数学上这叫自相似，[分形](../math/07-fractals.md) 那篇接着讲；
代码里则是一个跑 `turns × 4` 次的 `for` 循环——纹样的「写法」和算法的「写法」本来就是同一件事。

## 一分钟看懂

| 元素 | 云纹 | 雷纹 |
|---|---|---|
| 线条 | 圆弧卷曲 | 方折回转 |
| 象形 | 天上的流云 | 空中的电光 |
| 用途 | 主体边缘的连续带 | 大面积"地纹"填充 |

:::note 一句话
**云雷纹是中国人最早把"看不见的气"画出来的尝试**——用线条的循环暗示宇宙的运行。
:::

## 💡 练习题

1. **拖动验证**：把[云雷生成器](/lab#leiwen)的圆角从 0 一路推到 1，图形的"气质"发生了什么变化？为什么说古人是把云和雷画进了同一套语法？
2. **铺法推理**：每行 3 个螺旋、相邻格旋向相反时，图案能"咬得住"；把「相邻格旋向」切成全部同旋，缝隙出现在哪里、为什么？
3. **跨栏一问**：云雷纹的方螺旋"每转两段、边长加一个步长"。这个动作和[分形](../math/07-fractals.md)共享的性质是什么？

<details>
<summary>参考答案</summary>

1. 方折变圆润，冷硬的电光感变成绵软的流云感——同一份几何只改一个"拐角"参数就换了名字。古人手上没有"圆角"这个开关，但他们用的是同一条轮廓线：方折版叫雷纹铺地，圆弧版叫云纹走边，所以是同一套语法的两种渲染。
2. 全部同旋时每个螺旋的开口都朝同一侧，邻格的缺口无法互补嵌合，格与格之间留下成排的空白通道；异旋则一个顺时针一个逆时针，前者的凸处正好填后者的凹处，铺出来才是无缝的满地纹。
3. 自相似：同一个形状在不同尺度上重复出现，边长按步长递增意味着"放大看还是它"——这正是分形的核心，也是铜鼓地子上那种"越看越深"的来源。

</details>
